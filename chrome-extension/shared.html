Shared templates

Saved templates normally stay in one Chrome profile. Pick one file on this computer and every Chrome profile that points at it will share the same saved templates - add, edit or delete in one place and it shows up in all of them.

Checking...
First profile: create the file.
  1. Click "Create the shared file".
  2. Choose a folder every profile can reach (for example Documents) and click Save. If Chrome asks to allow editing the file, allow it.
Every other profile: use the same file.
  1. Click "Use the existing shared file" and pick FamFitHelper-templates.json from the same folder.
  2. If Chrome asks to allow editing, allow it.

Chrome may ask you to allow access again after you restart it - open the popup and click "Reconnect". Don't edit the file by hand. Keep a backup copy of it somewhere safe.
